Riyadh Land Price Prediction

Machine learning model designed to predict real estate and land prices in Riyadh districts to improve property valuation accuracy

Project Overview
- Source - Official Saudi open data platform provided by SDAIA
- Features - District total area transaction price and location features

Data Preprocessing
- Outlier Handling - Interquartile Range IQR method
- Encoding - Label Encoding for categorical district values
- Scaling - StandardScaler for feature normalization

Model Performance
- Algorithms Evaluated - Linear Regression Decision Tree Regressor and Random Forest Regressor
- Best Performing Model - Decision Tree Regressor achieving 92.11% accuracy

Tech Stack
- Programming Language - Python - SQl
- Libraries - Pandas NumPy Scikit-Learn Matplotlib Seaborn
- Environment - Google Colab
